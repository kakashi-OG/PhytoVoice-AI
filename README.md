# PhytoVoiceAI — Giving Plants a Voice

PhytoVoiceAI is a plant communication platform that explores the use of Artificial Intelligence and Internet of Things (IoT) technologies to improve the way humans understand plant health.

The project aims to create an interactive system that can interpret plant health signals and translate them into meaningful information, making plant monitoring more accessible and intuitive.

## Overview

Plants respond to their surroundings through various biological and environmental signals. Understanding these signals can help identify changes in plant health and improve plant care practices.

PhytoVoiceAI explores how technology can be used to monitor plant conditions and make this information easier to understand through a web-based interface.

The project is designed with future integration of AI-based plant health analysis, environmental sensors, and voice-based interaction in mind.

## Features

* Responsive and interactive web interface.
* Plant communication concept based on natural-language interaction.
* Proposed IoT-based plant monitoring system.
* Planned integration of environmental sensors for monitoring soil moisture, temperature, and humidity.
* Future scope for AI-based plant disease detection and voice interaction.

## Getting Started

### Prerequisites

* A modern web browser
* Git
* Visual Studio Code (recommended)

### Installation

Clone the repository:

```bash
git clone https://github.com/kakashi-OG/PhytoVoice-AI.git
```

Navigate to the project directory:

```bash
cd PhytoVoice-AI
```

Open the project in Visual Studio Code:

```bash
code .
```

Open the main HTML file in your browser to run the website locally.

For local development, the Live Server extension in Visual Studio Code can also be used.

## Deployment

The project website is deployed using Vercel.
